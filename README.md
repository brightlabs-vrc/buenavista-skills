# Official Bright Labs' Skillset for First-Party/Certified Maps

This repo contains the skills that are available for our maps and required to be shipped as a baseline for certified third-party maps. The skills themselves have been rigorously tested and balanced during active playtests
but contribution/discussion about their balance should take place here

## Contributing

At the moment, the core BuenaVista SDK to make this update easier is currently internal, with an eventual open-source release soon, but to encourage contributions, the current workflow is:

- Reach out to any of the gameplay designer(s):
   - [@xsqueaky45](https://github.com/xsqueaky45)
   - [Vissy-1](https://github.com/Vissy-1)
   - [GenesisOfKosmo](https://vrchat.com/home/user/usr_a0546187-3643-4afe-9f98-0d840290d931)
 - Explain what needs changing/what needs working on
 - Make a JSON Edit/discuss with the designers over at our Issues board and/or via Discord (PS: if you haven't please apply and indicate who you are)!

## For Designers

At the moment, tooling is internal, so you are responsible for updating the skills here from the internal Buena Vista Repository. Your workflow is the following:

- Discuss with the proponent about the changes
- Work with the changed values in Editor
- Certify a playtest with the lead developer for a live build
